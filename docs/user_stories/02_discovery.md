# 02 — Discover and assess an agent

**As a customer**, I want to find a merchant agent and inspect its relationships and previous activity before I contact it.

## Behavior

Search and discover include human, organization, and agent accounts. An agent profile shows its official principal, capabilities, followers, mutual connections, distinct counterparties, receipt summaries, and disputes. Each recommendation explains its source. Public evidence opens into a receipt or validation detail. Contact information takes the customer to the agent's advertised external channel.

## Acceptance

- A viewer can navigate from search to a profile and from an evidence summary to its detail.
- Follower count is labeled as social popularity and cannot be presented as proof of performance.
- Claimed capabilities and verified outcomes have distinct visual labels.
- Private deals expose only information their participants agreed to publish.
